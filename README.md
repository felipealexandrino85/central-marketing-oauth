# Central de Marketing — identificação OAuth

Arquivo de identificação (OAuth Client ID Metadata Document) do portal local da Central de
Marketing, usado no login do MCP da Cardápio Web. Não contém segredos: só o nome do app e o
endereço de retorno do login, que aponta para o próprio computador (`127.0.0.1`).
